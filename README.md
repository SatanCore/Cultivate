# Cultivate — Путь Бессмертного

Android-игра на Kotlin и Jetpack Compose в жанре cultivation / xianxia.

## Сейчас в проекте
- накопление Ци и прорывы между ступенями культивации;
- арена с противником и наградами за победу;
- развитие духовного спутника — Нефритового лиса;
- локальное сохранение прогресса через SharedPreferences;
- автоматическая сборка debug APK через GitHub Actions.

## Сборка
Откройте проект в Android Studio или запустите workflow **Build Android APK** в GitHub Actions. После успешной сборки APK будет доступен в артефактах запуска.

## Статус разработки
Это ранний игровой прототип. Баланс, художественные ресурсы, расширенная система техник, экипировка, события мира и полноценные игровые циклы будут развиваться постепенно. Сборка должна быть подтверждена CI; пока статус сборки не заявляется как успешный.
