# План импорта графики Cultivate

## Готовые фоновые ресурсы
В архиве `Cultivate_FULL_ART_SOURCE_PACK.zip` подготовлены четыре отдельные WebP-панорамы, а в `08_android_import/drawable-nodpi` им присвоены имена уже существующих ресурсов:

- `world_mortal_bg.webp` — Мир Смертных
- `world_spiritual_bg.webp` — Мир Духов
- `world_immortal_bg.webp` — Мир Бессмертных
- `world_chaos_bg.webp` — Мир Хаоса

Для ручного тестового импорта скопировать эти четыре файла в `app/src/main/res/drawable-nodpi/`, предварительно сохранив текущие фоны. Kotlin-ссылки на ресурсы уже существуют, поэтому менять код для первой проверки не нужно.

## Остальные исходники
Персонажи, боссы, питомцы, предметы, навыки и UI пока представлены отдельными иллюстрациями и концепт-листами. Не подключать сводные листы как игровые иконки: их нужно нарезать, очистить и проверить отдельно.

## Контроль
После добавления фонов выполнить GitHub Actions `assembleDebug`, затем проверить кадрирование на реальном устройстве. Архив исходников пока не загружен в GitHub; этот файл фиксирует схему импорта.


## Отдельные персонажи (подготовлены, ожидают загрузки)

В архиве `Cultivate_Character_Cutouts_Import.zip` находятся восемь PNG с прозрачным фоном. После загрузки в `app/src/main/res/drawable-nodpi/characters/` можно использовать такие ресурсы:

- `blademaster_male.png`, `blademaster_female.png`
- `ironbody_male.png`, `ironbody_female.png`
- `elementalist_male.png`, `elementalist_female.png`
- `spiritmystic_male.png`, `spiritmystic_female.png`

Перед ссылкой из Kotlin необходимо добавить изображения в Android-проект и объявить ресурсные ссылки; старые четыре портрета пока остаются резервным вариантом. PNG вырезаны из концепт-листа автоматически, поэтому требуется визуальная проверка краёв на устройстве.


## Отдельные существа и боссы (подготовлены, ожидают загрузки)

В архиве `Cultivate_Illustrations_Android_Import.zip` добавлены шесть PNG с прозрачностью: `celestial_dragon`, `magma_warlord_tiger`, `frost_phoenix`, `abyssal_demon_lord`, `jade_qilin`, `nine_tailed_fox`. Их можно положить непосредственно в `app/src/main/res/drawable-nodpi/` вместе с восемью вариантами персонажей. Это статичные иллюстрации, не анимации и не 3D-модели.


## Расширенный UI-концепт-лист

В полном архиве `Cultivate_FULL_ART_SOURCE_PACK_v5.zip` добавлен `05_concept_sheets/cultivate_comprehensive_ui_asset_atlas.webp` и его PNG-оригинал. Он служит визуальным справочником для будущей переработки меню, кнопок, рамок, HUD, экранов миров и навыков. Не подключать весь лист как одну текстуру интерфейса: сначала выделить отдельные компоненты, проверить их границы и подготовить размеры/варианты состояний.
