# Cultivate — исходные концепт-атласы

Сюда складываются исходные художественные атласы проекта. Загруженные PNG пока лежат в корне репозитория; их оригиналы сохранены. Это концепт-листы, а не готовые нарезанные игровые спрайты. После разметки элементы нужно нарезать, подготовить и экспортировать в подходящие размеры и форматы.
